Conexión con la API de agentes

Introduce la URL base y el token de acceso para conectar ArchIA con el backend real. Si no los tienes aún, el panel funciona en modo simulado.

Contrato de API esperado

POST /auth/login {email,password} → {token, user} POST /projects {name} → {project_id} POST /projects/:id/files multipart → {file_id, name} POST /projects/:id/analyze {} → {job_id} GET /jobs/:id → {status, progress, recommendations} POST /projects/:id/report {...} → {report_id, download_url}

Todas las peticiones autenticadas envían Authorization: Bearer <token>.
